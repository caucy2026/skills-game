# 集群资源预算和调试收尾

## 真实数据根与历史记录核验（2026-10-09）

维护页返回 `trustedRegistryEmpty` 或 `ownedDebugOnly` 仅证明当前可信登记范围为空，不证明历史现场已清理。先用实际 SDK owner 与平台存储布局核对数据根；Windows 的 LOCALAPPDATA 回退目录可能并非交互用户正在使用的 Roaming 根，macOS 的 AppScoped 布局也可能附加一层 Vibekits。不要从空目录推断历史不存在。

旧分析记录可能有多种标题。用原创建者源码、精确测试 workspace/cwd、创建时间及 UUID 清单证明归属，标题只作辅助；不得仅按名称前缀或年龄批删。固定会话若也是本次自有闲置调试记录，仍按用户清理范围处理；仅有实际活动任务、队列、租约或审批时保留，不能因“固定”永久豁免。

跨盘隔离的 rename 可报 EXDEV；保留首次结果并确认零改动/索引恢复，再按同一精确清单复制、逐文件 SHA 验证、移除源，保留可恢复证据。不得为此搬走凭据或整个用户目录。清理后分别核对原始记录、投影和 workspace 引用，冷启动再查目标未复活及非目标不变；原 ID/MCP 和客户端、云端房间另验。

本轮155两条确证自有记录移出后冷启动无复活；529此前8431条旧分析在576覆盖后仍为零，业务记录保留。58的576覆盖及原 ID/MCP/房间 ACK 已通过，维护元数据实际2.41秒返回；58旧记录清理仍需其独立终态，不能从升级或空 registry 推导通过。

管理与分析按room/device/workspace复用一个维护会话；业务执行仍按独立实例/当前合同/权限/fence/租约隔离。心跳、目录、设备事实默认确定性，不调用付费模型；仅真实有效任务或用户明确请求才分析。无Key/欠费停模型重试，不停MCP、入房、资源事实与已授权确定性操作。

重复事件按合同hash/step/configuration epoch去重，有限退避。401/402停到真实配置改变；超时先查原操作，不能重建会话或重签/重装。缓存只节省重复描述，不是新模型健康证明或执行许可。分析1024/描述512输出token和64KiB描述输入是已审源码上限，不是全上下文/总费用预算；实际安装版本须另核。固定会话的上下文需预算和当前request/seq/turn切片，不把旧回答算本次完成。

开始登记精确自有session/artifact/process/目标、用途及回退；结束收队列/租约、闲置测试会话与可再生工件。先现有智能体；权限或模型不可用时用已授权仿真终端，不为每个维护动作另发App。不能以同名或目录年龄代替身份/归属证明，也不能把业务、凭据或事故证据清掉。

清理先冻结ID/标题/创建时间/原文件hash和非目标范围，用现有正式生命周期。离线管理须先备齐恢复、正常暂停真实所有者、全部writer退出和独占事务；只TERM SDK可能被App自动拉起，不是单写者证明。按有界批次/journal/资源观察执行，不海量Promise或回包。移入可恢复隔离须如实称移出工作环境，不叫物理永久删除；只留一次有期限回退，收掉重复备份。

完成后列表/搜索/正常重载或冷恢复不复活，原业务保持，原ID新握手/实际MCP/client room/cloud新鲜心跳复验。缺before raw hash不声称全字节不变；可记录已捕获事件canonical前后比较的范围。计划维护断联单列实际UTC起止，不能当异常故障或连续在线。GUI坐标/键盘动作前核frontPID/window；其他用户切焦点就停止，不反复抢前台或用其他App截图算PASS。

已遇经验：数千旧同名可能是历史加载，不证明新版本在创建；先按创建时间/总数两次采样核新增长。一次模型回复completed不能证明清理；只关新循环不能替代收掉旧现场。源夹具通过不能替代真设备；费用没有provider账单不能推算。项目CE-01～15、VH-05/MH-03与月度严重故障台账为验收依据。

## 本地 MCP 协议与收尾（2026-10-08）

本地管理工具返回慢时，先核对真实调用PID、父链、脚本与TCP；进程可能以Node命名，不能按hbbv/mcp名字匹配空就判未启动。日志/启动参数仅输出必要脱敏字段，禁止打印密码、token或环境全集。管理目录online/callable是可调用线索，不是调用完成证明。

已遇事故：成功结果已取得，但finally先等待async*管道流取消，子进程仍开管道，使外部响应挂起；静默、持续通知与正常成功三例均可重现。修复先结束本次专属子进程再有界取消流，响应采用绝对deadline，通知不延长等待。真实故障恢复只处理已核身份的自有查询子进程，不按进程名全杀、不重启客户端或重复写请求。原请求终态与子进程退出一起核验。未部署新包不能称生产修复生效。

发布必须以同一冻结源码对实际包内辅助脚本和技能逐文件hash核验。构建/签名/公证成功仍可能漏入本轮JS修复；同步runtime投影后生成唯一新候选，不能热改已签包或用版本号代替载荷证据。不同代理的执行session句柄不可见时，原执行代理继续观察同run；Root核PID/日志，不能据此判断构建已死或重启。

## 固定会话不等于固定授权任务

575签名前实际发现：UI把批准按sessionId/toolName/reason持久到localStorage，并对后续匹配直接allowed-once；同一维护会话承担新任务/新实例时这些字段可不变，因此不能证明授权范围连续。真实helper已复现旧批准跨请求碰撞。已阻止签名部署，取消该注入并精确恢复合格572原审批模块，保留普通PendingApproval允许一次/拒绝，不清用户原凭据或OS权限。

同工作授权延续以当前对象、操作、任务/实例、政策和权限范围为依据，不能由会话标题或reason字符串替代。固定会话是节省上下文与资源，不是跨实例借许可。发布回归必须含旧不安全payload负控；原先主动要求错误记忆存在的测试PASS不是安全证据。源修订、AOT复用和最终payload各自hash/收据闭合，不把上一候选编译成功当本候选发布通过。
