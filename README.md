备份日期：2026-10-05（北京时间）。来源：本机 Codex 全局技能目录。

每个技能独立存放，包含 SKILL.md、引用文档、脚本及 agents 配置（如有）。

- swdol-acceptance-handoff：验收和两小时交接
- swdol-client-compatibility：客户端兼容研发
- swdol-database-operations：数据库查询与状态对齐
- swdol-document-governance：开发文档治理
- swdol-server-compatibility：服务端兼容研发
- swdol-static-dynamic-analysis：静态与动态分析
- swdol-xp-control：原版 XP 客户端控制
- client-server-dynamic-trace：前后台动态插桩
- evidence-driven-engineering-manager：研发监督
- project-handoff：项目目标与续做交接
- vm-smb-file-delivery：虚拟机文件投递
- safe-build-cache-cleanup：安全构建缓存清理

这些技能引用的外部项目源码、证据、工具链和虚拟机不包含在此备份中。迁移到其他机器时需核对路径、环境及授权；技能副本本身不代表环境已就绪。
